# Real initial-child implementation review

`reviewer_review_initial.py` reconstructs a review subject for a real initial
coding child after the separately signed integration, candidate and final
creator/reviewer suites. It replays those receipts, verifies the approved plan
against the fresh creator signature, and takes the full binary Git diff from
the signed base to the integrated commit. The subject also hashes a lineage
record naming the child, integration, source binding, candidate and final-suite
receipts.

The compatibility context lets the existing owner-attested two-provider
critic/judge gate assess that exact subject. It retains the original gate's
explicitly non-independent claims. Every live provider request still requires
its own exact one-use spending grant. This module performs no provider call,
repository write, or acceptance.
