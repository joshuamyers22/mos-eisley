## Threat boundaries

Owner-private files authorize a local same-owner session; they are not signatures against host compromise or receipts of provider billing. Binary hashes and native version bind compatibility/trust, not publisher authenticity. The native client owns account authentication/refresh; authentication location is a local binding and does not independently attest the remote account. Managed native policies remain a trust dependency. Prompt data and provider output grant no tools, file access, role authority or release authority. Full request hashes must include schema and caps. Local locks and durable slots enforce invocation admission; native internal retries and remote completion after cancellation remain uncertain. Saved transcript artifacts use ordinary private conversation storage and are never sampling artifacts.
