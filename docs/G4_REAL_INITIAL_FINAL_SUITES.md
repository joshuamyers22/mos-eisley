# Real initial-child final suites

`reviewer_initial_final.py` admits two offline whole-suite runs after the
signed real initial-child candidate passes. A separate Joshua creator signature
binds the integrated Git commit, signed integration, candidate receipt, fresh
creator package, reviewer package, source binding, exact requests and immutable
container image. The claim is one-use and is separate from the candidate claim.

The creator package contains the protected creator tests from the signed base
commit. Its references bind the fresh initial creator approval and the approved
plan, interface and rubric. Preflight checks those bytes at the base and
integrated commits. The reviewer suite must execute the same test identities as
the passing candidate. Both results are replayable from the saved receipts.

This gate authorizes neither provider calls nor source writes, review or
acceptance. The controller is exercised by the owner-local
`g4_initial_final.py` script, which pins its Git revision before use.
