## Scope and separate acceptance

This amendment grants no provider call, spending, source write, merge, release,
production activation or creator acceptance. A separate quality-applicability
decision and separate creator acceptance must bind the completed review and
exact task evidence. A single connected run does not establish representative
quality, savings, routing benefits, G3 empirical completion or full G4 milestone
acceptance. No sampling or holdout evidence is part of this decision.
