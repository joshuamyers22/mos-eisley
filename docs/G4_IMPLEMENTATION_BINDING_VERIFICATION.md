## Budget and stopping rules

- Maximum iterations: four evidence-changing passes.
- Elapsed-time or review window: one offline implementation session.
- Compute/cost ceiling: local static/tests/build only; no live provider calls.
- Pass rule: all blocking rows pass, no unresolved high-severity code finding, full
  repository and installed-wheel evidence accounted for.
- Diminishing-return rule: stop after a clean full gate and source-level threat pass.
- Escalation/domain-input trigger: unknown runtime/VCS authority or need to loosen an
  oracle returns to the project owner and a later slice.
- Rollback or abort condition: any import/execution path, mutable record, incomplete
  source-root inventory or authority escalation.
