# Milestone 86 adversarial review: partial OpenAI calibration seed

## Disposition

Accepted as an offline, exact-lineage conversion of the 18 aggregate-approved
OpenAI conformance successes into a private partial calibration seed. Rejected as a
complete `RawResultSet`, a representative or adequately powered quality sample,
provider authorship, billing reconciliation, grading or scoring authority, routing
promotion, activation, production readiness, or authority for another request.

## Adversarial findings

| Attack or ambiguity | Disposition | Remaining boundary |
| --- | --- | --- |
| A forged pass-shaped report authorizes conversion | Require the exact publicly pinned aggregate-report digest and canonical unique-key JSON | Repository review and retained report custody remain trusted |
| The two invalidated Astra/high successes are smuggled back in | Require the exact 18 qualifying sample/position/profile set and exactly 18 matching receipts and artifacts | A future policy change is a new reviewed lineage |
| A receipt or artifact is substituted after aggregation | Match its canonical hash plus request, route, authorization, outcome, response, ledger, latency, cost, and usage identities | The converter relies on the aggregate's prior audit/signature/ledger reauthentication instead of replaying it |
| Eighteen samples are called complete calibration | Encode 18 converted versus 360 batch assignments and literal false complete-batch coverage | The remaining complete-batch execution boundary is not implemented |
| The seed is passed into legacy grading | Use a distinct schema that fails `RawResultSet` parsing and retain false raw-result and grading issuance | Future code must preserve that type separation |
| Route identities leak to an adjudicator | Keep the seed private and explicitly prohibit direct grader export | A future complete converter must generate route-blind grading material through the existing pipeline |
| Conversion silently makes a live call | Refuse both supported key variables, require explicit offline consent, and expose no provider or spend port | Same-UID environment/process inspection remains outside the local proof |
| Small selected samples are treated as model quality evidence | Keep quality, scoring, promotion, and activation false | Complete representative calibration and one-use holdout evaluation remain required |

## Gate effect

The reviewed 18-record partial conversion is complete. It can seed planning and
lineage accounting, but it cannot enter grading or routing calibration. Next, design
the complete-batch brokered calibration boundary: preserve the frozen 360-assignment
matrix, define fresh request/spend authority, retain terminal failures, and issue a
gradeable result only after exact full coverage and another adversarial review.
