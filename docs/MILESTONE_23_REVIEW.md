# Milestone 23 adversarial review: paired skill evidence

## Disposition implemented

Persona migration is no longer merely a plan note. Mos Eisley now binds exact
reviewer instructions into candidate and request identity, seals a two-arm
prompt-only experiment, consumes holdout once through a private exclusive claim,
and computes paired independent-group bounds only after reverifying the complete
dual-authenticated grading lineage.

The evidence remains non-promoting and non-activating.

## Adversarial findings addressed

- A model/effort candidate without its instructions does not reproduce the treatment,
  so every route now contains a content-addressed `PromptAsset`.
- A skill version label does not identify bytes, so the treatment carries the
  source-qualified whole-package `SkillIdentity` and exact instruction body.
- An apparent skill win can actually be a model, effort, provider, client, or
  registry change, so sealed arms may differ only by prompt asset.
- Unpaired aggregate scores discard useful covariance, so deltas pair each case and
  repetition before equal-weight independent-group aggregation.
- Repeated trials are not independent evidence, so they are averaged within cases
  and never increase the group count.
- Choosing metrics or stopping after seeing results invites researcher degrees of
  freedom, so dataset, plan, arms, margins, fixed matrix, estimand, confidence family,
  and holdout rule are all sealed first.
- Repeated holdout inspection permits selective reporting, so the CLI consumes a
  lineage-bound claim before it verifies or scores and refuses a second attempt.
- A computed pass can be mistaken for deployment authority, so seal, claim, and
  report schemas contain literal activation denial and reports contain literal
  promotion denial.
- A forged summary could disagree with its component gates, so report validation
  recomputes the conjunction and rejects inconsistent serialized artifacts.

## Remaining limits

The exclusive claim is a local control: the owning user can delete it, copy state to
another machine, or call library functions outside the CLI. There is no signed
promotion decision, default-persona mutation, automatic routing connection, skill
archive, rollback mechanism, expiration policy, or post-promotion drift monitor.

Hoeffding bounds are conservative and depend on honest, meaningful independence
groups. Cost and latency diagnostics are paired but do not currently have confidence
intervals. The two human graders can share bias or infer arms from output style.
Passing one registered comparison establishes evidence for that dataset and artifact
chain only; it does not establish general quality or safety.
